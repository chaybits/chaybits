# ChayBits

Small tools for KDE Plasma, Windows and AI coding agents.

## Being worked on

- ChayRig: A Terminal Rig that enhances using Claude Code, Codex, and Antigravity. My biggest project yet, being built from scratch (For Windows, Linux and MacOS)
- ChayMeter: A complete overhaul to Ai Session Manager; UI change, options to see how much each model fills the quota, its API price equilavent etc. (For Windows, Linux and MacOS)
- ChayWE: A companion app that lets you run Wallpaper Engine on Linux as well as on Windows. A project needing long testing times, and first release will take some time.

Updated 2026-10-28.
